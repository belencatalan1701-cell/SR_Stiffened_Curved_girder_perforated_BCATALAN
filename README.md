# SR_Stiffened_Curved_girder_perforated_BCATALAN
Desarrollo de un algoritmo genetico mediante librerias abiertas para predecir una expresion de coeficientes de pandeo especifico para vigas de acero de almas curvas con perforacion circulares , esta rutina es suministrada de una base de datos de valores despejados de kf los cuales fueron obtenidos con FCR y ANSYS.
